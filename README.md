# BPLab Trace V8.3 — GitHub / Streamlit 运行包

本目录只包含程序运行所需文件。

## 部署

1. 将本目录内的全部文件上传到 GitHub 仓库根目录。
2. 在 Streamlit Community Cloud 中选择该仓库。
3. Main file path 填写 `app.py`。
4. 部署并打开 HTTPS 地址。

系统首次启动时会自动创建 SQLite 演示数据库，并初始化 83 条样品信息。

## 本版重点

- 实验员进入实验过程后自动记录开始时间，仅手动结束实验。
- 对照受控原始记录母版补充现场观察、设备溯源和各实验专项确认字段。
- 检验报告自动选取各实验的决定性结果照片，并显示样品、节点、时间和结论。
- 检验报告发放登记表和危废登记表直接填充实验室提供的受控 DOCX 模板。
- 样品登记表的型号/规格填写区支持自动换行并增高，长型号不再截断。
- 独立修改日志只显示修改、作废、更正和照片替代，并可下载中文 PDF。
- 异议调查追溯 Excel 精简为调查总览、数据与照片对应、关键时间轴、
  修改与版本、完整原始数据和照片证据目录六个页签；不显示程序字段、
  内部路径、哈希或内部关系字段。
- 样品管理员手工登记异议并生成申请表；质量检测员查看追溯 Excel 和修改日志
  后判定“是我们的问题/不是我们的问题”；样品管理员记录客户重测决定、
  从样品库派发重测并生成、发送异议回复。
- 管理员异议页面提供一键准备“已有签发报告”的专用测试 Demo，样品管理员负责录入申请。
- 管理员可在报告发放登记页面直接对已发放报告执行作废或启动更正流程。
- 争议检测项目只能从原委托已选择的实验项目范围中勾选，后台再次校验，不能写入委托外项目。
- 质量调查工作台可按任务勾选照片编号、原始记录中文字段和其他追溯资料，并填写核查结果、备注、影响范围及处理建议。
- 样品管理员记录客户决定时只保留“需要重测/不需要重测”，删除“待处理”。
- 复核退回后自动冻结被退回版本并复制全部数据生成下一版二次编辑草稿；实验员收到弹窗并在实验窗口看到醒目标识和复核意见。
- 五个角色首页均可按样品组查看收样、入库、派发、领用、实验、复核、归还、回库及处置时间轴。
- “符合/不符合”等复选项只根据明确录入值生成，不再静默勾选默认结论。
