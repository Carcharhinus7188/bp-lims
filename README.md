# BPLab Trace V6.0 流程重构演示版

本项目是大连标普检测有限公司实验室样品全过程追溯系统的
Streamlit Demo。业务流程按最新确认的五角色模型重构：

- 管理员
- 样品管理员
- 实验员
- 复核员
- 质量检测员

## 核心流程

1. 样品管理员建立委托、收样、生成样品组和实体样品编号。
2. 系统按样品组自动形成待下发实验；样品管理员只选择实验员。
3. 系统自动匹配复核员和质量检测员，并冻结SOP、模板和设备配置。
4. 实验员领样，按系统时间轴开展实验，填写全部原始数据。
5. 每个强制拍照节点只能使用平板现场相机；系统保存原图、带服务器
   时间戳副本和SHA-256。
6. 实验员自检提交，复核员独立复核，不允许直接改写实验数据。
7. 复核通过后系统自动生成报告初稿。
8. 质量检测员审核报告完整性和正确性。
9. 管理员承担授权签字人职责，完成最终审核和签发。
10. 样品管理员登记报告发放、样品回库、留样和后续处置。
11. 系统自动形成内部实验数据追溯工作簿和不可覆盖的修改日志。

## 客户异议

系统提供两条固定路径：

- 检测方法或实验室实施问题：管理员确认后原报告作废，样品管理员
  询问客户是否重测；需要时可使用留样生成新任务。
- 样品自身问题：质量检测员通过完整追溯证据说明实验室过程正常，
  管理员签发回复，原报告继续有效。

所有异议均保留受理、调查、审批、客户决定、回复和归档时间轴。

## 现场相机

实验任务页使用 `st.camera_input` 调用平板摄像头，不提供图片文件或
截图上传入口。设备原始数据文件可在独立入口上传。每次重拍均保留旧
照片并标记“已替代”，不会覆盖或删除。

## SOP与原始记录

当前10组SOP和原始记录以用户最新提供的
`sop-实验原始记录` 文件夹为准。程序内的受控副本位于 `templates/`。

其中编号按最新确认统一：翘曲变形为 `SOP-006`、热膨胀系数为
`SOP-007`、弯曲性能为 `SOP-010`；其余项目与配套原始记录编号一致。

## 本地运行

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Community Cloud

1. 将本目录完整上传到GitHub仓库。
2. 在Streamlit Community Cloud中新建应用。
3. Main file path填写 `app.py`。
4. 部署后使用HTTPS地址访问；平板相机需要HTTPS权限。

SQLite数据库和照片演示存储位于 `data/`。Streamlit Community Cloud
重启或重新部署时本地文件可能丢失，因此本版适合流程演示，不应直接
作为生产数据存储。生产环境应更换为持久数据库和对象存储。
