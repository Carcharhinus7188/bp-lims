# BPLab Trace V9.3 — GitHub / Streamlit 与阿里云运行包

本目录只包含程序运行所需文件。

## 部署

### 阿里云 ECS（正式互联网入口）

本包已包含 Docker、Caddy HTTPS、持久化数据目录、每日备份和恢复脚本。请直接阅读
《阿里云ECS部署说明.md》。服务器端只对公网开放80/443端口，不开放Streamlit的8501端口。

### Streamlit Community Cloud（演示）

1. 将本目录内的全部文件上传到 GitHub 仓库根目录。
2. 在 Streamlit Community Cloud 中选择该仓库。
3. Main file path 填写 `app.py`。
4. 部署并打开 HTTPS 地址。

系统首次启动时会自动创建 SQLite 演示数据库，并初始化 83 条样品信息。

## 本版重点

- 安卓平板和iPad拍照默认优先启动后置摄像头，取景区可直接切换前/后摄；受浏览器限制时可调用系统相机并优先后置镜头。
- 所有角色的受控Word预览改为服务器高保真逐页渲染，直接显示实际DOCX的分页、表格、签名和照片；不再依赖会改变复杂报告格式的网页解析。
- 质量负责人和管理员在报告中心查看检验报告时，统一使用实验员、复核员原始记录复核所用的受控 Word 阅读器；审批期间仅预览，不提供审核文件下载。
- 五个角色已初始化各自的电子签名图片；受控单据中的签字位置自动粘贴对应签名图，不再用姓名文字代替签名。
- 删除独立 Word 预览入口，受控单据统一在对应业务审核页面和单据中心查看。
- 复核退回后二次编辑实行字段级锁定，实验员只能修改复核员明确指定的字段。
- 检验报告首页“核验员”对应复核员、“检测员”对应实验员，并粘贴各自签名图片。
- 五角色界面统一改为稳重、低干扰的实验室受控工作台风格。
- 质量负责人报告中心恢复醒目的待审核指标和报告审核入口，并自动修复旧数据中缺失的质量负责人。
- 管理员新增“系统初始化”：先下载备份，再经复选和指定文字二次确认后清空业务历史；用户、签名、单位库、样品基础库、设备、配置、SOP和模板保留。
- 界面按现代管理系统重构为浅灰工作区、白色圆角卡片、低饱和度蓝灰选中状态和顶部日期栏。
- 左侧导航进一步改为浅色、低饱和度分组样式；各角色最常用入口置于首组“工作台”，其他功能按业务、追溯、配置和系统管理折叠展示。
- 修复样品组流转时间轴在收样结论为空时的报错。
- 原始记录编号使用实验任务编号，报告编号由任务编号的 `BP` 前缀替换为 `R`，照片文件名使用任务编号和拍摄时间。
- 实验员进入实验过程后自动记录开始时间，仅手动结束实验。
- 对照受控原始记录母版补充现场观察、设备溯源和各实验专项确认字段。
- 检验报告自动选取各实验的决定性结果照片，并显示样品、节点、时间和结论。
- 检验报告发放登记表和危废登记表直接填充实验室提供的受控 DOCX 模板。
- 样品登记表的型号/规格填写区支持自动换行并增高，长型号不再截断。
- 独立修改日志只显示修改、作废、更正和照片替代，并可下载中文 PDF。
- 异议调查追溯 Excel 精简为调查总览、数据与照片对应、关键时间轴、
  修改与版本、完整原始数据和照片证据目录六个页签；不显示程序字段、
  内部路径、哈希或内部关系字段。
- 样品管理员手工登记异议并生成申请表；质量负责人查看追溯 Excel 和修改日志
  后判定“是我们的问题/不是我们的问题”；样品管理员记录客户重测决定、
  从样品库派发重测并生成、发送异议回复。
- 管理员异议页面提供一键准备“已有签发报告”的专用测试 Demo，样品管理员负责录入申请。
- 管理员可在报告发放登记页面直接对已发放报告执行作废或启动更正流程。
- 争议检测项目只能从原委托已选择的实验项目范围中勾选，后台再次校验，不能写入委托外项目。
- 质量调查工作台可按任务勾选照片编号、原始记录中文字段和其他追溯资料，并填写核查结果、备注、影响范围及处理建议。
- 样品管理员记录客户决定时只保留“需要重测/不需要重测”，删除“待处理”。
- 复核退回后自动冻结被退回版本并复制全部数据生成下一版二次编辑草稿；实验员收到弹窗并在实验窗口看到醒目标识和复核意见。
- 五个角色首页均可按样品组查看收样、入库、派发、领用、实验、复核、归还、回库及处置时间轴。
- 实验提交检查统一显示业务字段、结束时间、自查确认和强制照片状态；提交按钮不再无提示变灰，缺项时明确显示阻断原因。
- 复核员退回时必须选择具体修改字段；实验员进入二次编辑后显示字段清单，并自动定位到首个指定步骤。
- 二次编辑草稿继承上一版本全部有效照片，拍照节点中直接显示留档照片；待复核 Demo 自动生成全套黑色测试照片。
- 单据中心按实验任务列出全部原始记录历史版本；复核退回后的 V1.0 与新建的 V2.0 草稿可同时查看并分别下载，不再只显示最终锁定版。
- 实验员提交前增加“受控原始记录补充字段核对”，自动读取母版仍未覆盖的确认项和填空项，逐项填写后回填原位置；任何缺项都会在界面和数据库提交层同时阻止提交。
- 修复未使用样品行被重新显示为未勾选选项的问题。十项受控模板 Demo 已完成全字段生成检查，无残留空白线或仅未勾选的必填单元格。
- “符合/不符合”等复选项只根据明确录入值生成，不再静默勾选默认结论。
